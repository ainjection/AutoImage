AutoImage — How To Use It

The one-file workflow: you write a JSON file of scenes, AutoImage feeds them to Google Flow one by one, and every finished image or video lands in a tidy folder on your PC. You never touch the Flow prompt box.

The basic loop (everything follows this)

  • Open your Flow project in Chrome (labs.google/fx/tools/flow).
  • Click the AutoImage extension icon (top right of Chrome).
  • Pick the MODE: Image, Video or Whisk.
  • Type a Project Name — this becomes the download folder name.
  • Load your JSON file. It shows how many scenes it found.
  • Press Start. Walk away.

Everything downloads automatically to Downloads/AutoImage/<your project name>/ — images as scene_01.jpg, videos as scene_01.mp4. When a scene finishes, the next one fires on its own.

The JSON file — simplest form

A JSON is just a list of scenes. The simplest file that works:

{
  "scenes": [
    { "scene_number": 1, "prompt": "A red fox in the snow, watercolour style" },
    { "scene_number": 2, "prompt": "The same fox curled up asleep, watercolour style" }
  ]
}

That's it. Image mode: each prompt makes one image. Video mode: each prompt makes one clip. Repeat your style words in every prompt so the look stays locked.

Automatic settings — the "settings" block

Add a settings block to your JSON and AutoImage sets Flow's prompt bar for you — mode, sub-mode, model, duration, aspect ratio and outputs. No more touching the tabs:

{
  "settings": {
    "mode": "video",
    "video_mode": "frames",
    "model": "Veo 3.1 - Fast",
    "duration": 8,
    "aspect": "16:9",
    "count": 1
  },
  "scenes": [ ... ]
}
  • mode: "image" or "video"  ·  video_mode: "frames" or "ingredients"
  • model: "Veo 3.1 - Fast", "Veo 3.1 - Lite", "Veo 3.1 - Quality", "Omni Flash", "Nano Banana 2"
  • duration: 4 / 6 / 8 / 10  ·  aspect: "16:9", "9:16", "1:1", "4:3", "3:4"  ·  count: 1-4
  • No settings block? Whatever Flow is currently set to gets used — set it by hand like before.

Video mode basics

Either use the settings block above, or set Flow's prompt bar yourself before pressing Start.

  • INGREDIENTS — reference images guide the clip (storyboard sheets, characters).
  • FRAMES — give it a start picture and (optionally) an end picture; it animates between them.
  • Models: Veo 3.1 Fast is the workhorse (10 credits / 8s). Use VEO for start/end frames — Omni Flash ignores end frames.
  • Videos download themselves and the queue moves on — no clicking.

Feature: start_frame / end_frame  (Video > FRAMES mode)

Add these to a scene and AutoImage loads the pictures into Flow's Start and End slots before prompting. The value is either the name of an image already in your Flow project, or the name of a picture you dropped into the popup's "Frame images" box (no need for it to exist in Flow — AutoImage uploads it the first time a scene uses it). Name files simply: image1.png → reference it as "start_frame": "image1".

{
  "scenes": [{
    "scene_number": 1,
    "prompt": "He flips the pancake; it sticks to the ceiling. No dialogue, ambient sound only.",
    "start_frame": "marco_pour",
    "end_frame": "marco_ceiling"
  }]
}
  • Flow must be in Video > FRAMES mode, model = Veo 3.1.
  • Unlocks before/after transformations, and seamless chains — use the last frame of clip 1 as the start frame of clip 2.

Feature: character  (Image mode, or Video > INGREDIENTS)

Attach a saved Flow Character to every generation so the design never drifts. The value is the character's name exactly as it appears in Flow's Characters tab.

{
  "scenes": [{
    "scene_number": 1,
    "prompt": "He carries a wobbling tower of pancakes across the kitchen. No dialogue, ambient only.",
    "character": "test1"
  }]
}

Creating a character (once per project): left sidebar → Characters → New, then describe them, Upload a photo, or "Add from Project" to use an image you already generated. Name it, add a one-line "how they act" description, press Done.

What it looks like when it runs: the character appears as a small picture chip in the prompt box just before the text goes in — the same thing you get manually by typing @ in the prompt and picking them, or by using the + button. Three doors, same room: the character rides along with the generation.

Important: characters belong to ONE project. A character made in project A does not appear in project B. And the character feature does NOT work in Video > FRAMES mode (that mode has no attach button) — use Ingredients.

House rules for video prompts

  • End every video prompt with: "No dialogue, no speech, no voices — ambient sound only." Veo generates audio, and stray speech fights your voiceover.
  • If a character SHOULD talk, give the exact line: he says: "right, that's done."
  • Lead the prompt with the CHARACTER, not the action — that's what stops design drift.
  • Test generations at the cheapest settings (1x, Fast model); only go big once the look is approved.

If something goes wrong

  • Scene stuck or skipped: check the extension popup — failed scenes show in red with a reason.
  • Wrong/no image attached: the name in your JSON must match the file/character name in Flow's media library.
  • After an extension update: chrome://extensions → AutoImage → press the refresh circle. Without this you're running old code.
  • Whisk mode pauses between prompts on purpose — that's rate-limit pacing, not a bug.
